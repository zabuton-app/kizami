Privacy Policy

Effective date: August 10, 2026

In short: kizami does not collect any personal data. It is a local application — your settings stay on your machine. The only network request it ever makes is an optional update check, described below.

Data stored locally

kizami stores two kinds of data, only on your device:

  • Application settings (timer durations, auto-start, task name, language, theme, window mode, and tray icon) are saved in a local configuration file.
  • Update-check state (whether the automatic check is on, a version you chose to skip, and when the last check ran) is saved in a second local file.

None of this data ever leaves your machine, and the developer has no access to it. kizami does not read, index, or modify any of your files.

Network access

kizami makes exactly one kind of network request: an optional update check. It queries the GitHub API (api.github.com) for the latest release of kizami to let you know when a new version is available.

  • The request contains no personal data or identifiers beyond what any HTTP request technically exposes (such as your IP address), which is processed by GitHub under the GitHub Privacy Statement.
  • The automatic check on startup can be turned off in the app's settings; updates can then only be checked manually.
  • kizami never downloads or installs updates by itself — it only tells you that a newer version exists.

Analytics and telemetry

kizami contains no analytics, telemetry, crash reporting, advertising, or tracking of any kind. There are no user accounts and no cloud services.

Third parties

kizami never shares your settings with third parties — they never leave your machine. The only third party involved is GitHub, which receives standard request metadata (such as your IP address) when the optional update check runs, as described under “Network access” above.

This website

This policy is about the kizami application. The website you are reading it on is hosted by GitHub Pages and loads its web font from Google Fonts; both services receive standard request metadata (such as your IP address) when the page is viewed, under the GitHub Privacy Statement and the Google Privacy Policy respectively. The website itself sets no cookies and contains no analytics.

Changes to this policy

If kizami's behavior ever changes in a way that affects this policy, this page will be updated and the effective date above will be revised.

Contact

Questions about this policy can be raised on the GitHub issue tracker.
